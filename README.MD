# CosySmart - API REST 

API REST oficial para **CosySmart**, una plataforma web y móvil diseñada para la gestión, exhibición y comercialización de muebles multifuncionales orientados a optimizar espacios pequeños.

## 🚀 Tecnologías Utilizadas

* **Entorno de ejecución:** Python
* **Base de Datos:** SQL Server / Relacional 
* **Control de versiones:** Git / GitHub

---

## 📋 Características Principales

* **Gestión de Usuarios:** Registro e inicio de sesión con roles diferenciados (Compradores, Vendedores y Administradores).
* **Catálogo de Mobiliario:** Endpoints para la administración y consulta de muebles multifuncionales, optimización de espacios y filtros por dimensiones.
* **Seguridad y Autenticación:** Protección de rutas mediante tokens.
* **Arquitectura Escalable:** Estructura modular orientada a controladores, rutas y modelos.
